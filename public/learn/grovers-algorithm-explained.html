Grover's Algorithm Explained With a 3D Simulation

Grover's algorithm searches an unsorted collection of N items for one that satisfies a condition. It needs about (π/4)√N iterations, while classical search needs about N/2 checks on average.

Each iteration has two steps. The oracle flips the sign of the marked item's amplitude. The diffusion step reflects every amplitude about the mean, which raises the marked amplitude a little each round.

Running too many iterations overshoots and lowers the success probability, so the iteration count must be chosen well. The speedup is quadratic, not exponential.

k ≈ (π/4)√N, P = sin²((2k+1)θ)

Frequently asked questions

Is Grover's algorithm exponentially faster?

No, the speedup is quadratic, and it is proven optimal for unstructured search.

What are real uses?

Speeding up brute-force style subroutines in search, optimisation and cryptanalysis of symmetric keys, where it effectively halves key length.
